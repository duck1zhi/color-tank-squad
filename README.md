# 彩色坦克小队

一个无需安装依赖、打开浏览器即可游玩的单人 Canvas 坦克游戏原型。

## 启动

直接双击 `index.html`，或在本目录运行：

```powershell
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 操作

- `WASD` / 方向键：移动
- `Space`：射击
- `P` / `Esc`：暂停或继续
- `R`：重新开始本局

游戏共有三章九关、十八波战斗：第 1～2 关各 12 辆，第 3～6 关各 15 辆，第 7～9 关各 20 辆，共 144 辆敌军。正常战斗阶段地图内会动态保持 3～4 辆敌军，最后清场阶段除外。

敌军包含强装甲、疾击、急行和远射等特殊类型。疾击炮弹会造成短暂破甲，并且能够逐步击毁普通炮弹无法破坏的钢铁掩体。玩家每关从基地左侧或右侧交替入场，每关完成后可从 18 种技能中选择一项升级。

第 5 关加入爆炸油桶，第 8 关加入反射炮弹的水晶墙，第 3、6、9 关分别拥有独立 Boss。关卡开始时会自动保存当前战役，刷新页面后可从首页继续。
